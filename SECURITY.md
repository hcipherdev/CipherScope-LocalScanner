# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in CipherScope Local Scanner, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email: hcipherdev@proton.me

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 72 hours and aim to release a fix within 14 days of confirmation.

## Scope

This policy covers the `cipherscope-local` CLI tool and its scanner modules. The tool is designed to be read-only and does not:
- Modify scanned systems
- Transmit data externally
- Store private key material
